# UC-03 — Sửa bug (`/fix`)

Owner: C. Code: `src/agents/fix.ts` (workflow), `src/commands/fix.ts` (lệnh), `evals/uc03/run.ts` (eval), `evals/issues/bug-NN/` (bộ seeded bugs), `skills/bug-fix/SKILL.md`.

## 1. Workflow

```
baseline ──► reproduce ──► locate ──► patch ──► verify ──┬─► keep ──► report
   │            │            ▲                           │
   │            │            └──── chưa sửa, < 5 vòng ───┤
   └─ lỗi ──────┴─ không tái hiện ──────────────────────┴─► report
```

| Node | Việc | Tool |
|---|---|---|
| `baseline` | Snapshot workspace (D2), chạy full suite làm mốc | `runPytest` |
| `reproduce` | Tìm hoặc viết test fail vì bug; `submit_repro` chạy lại target, phải fail hoặc treo | `read_file` `search_code` `list_dir` `apply_patch` `run_tests` `submit_repro` |
| `locate` | Một giả thuyết (file, hàm, lý do); không lặp giả thuyết đã loại | `read_file` `search_code` `list_dir` `submit_hypothesis` |
| `patch` | Diff nhỏ nhất; quá 3 patch lỗi thì hết vòng | `read_file` `apply_patch` |
| `verify` | Target phải pass, full suite không regression so với `baseline` | `runPytest` |
| `keep` | Hỏi "Giữ bản sửa?"; `no` thì hoàn tác qua `restoreFiles` (D2) | — |
| `report` | `FixReport`; diff > 3 file hoặc > 100 dòng thì kèm giải thích | — |

Giới hạn mặc định: 5 vòng, 200 000 token, 15 phút cho cả workflow. Mọi tool call qua `executeTool` + `decide()`; guard sửa test (C2) chặn sửa/xoá test có sẵn trong cả `apply_patch`, `edit`, `write_file`.

## 2. Eval

Chạy trên máy eval của D (Linux, bwrap):

```
npm run eval -- --uc 03          # 10 bug, model thật (@code)
npm run eval -- --uc 03 --mock   # chỉ bug-01, MockProvider có patch đúng: smoke pipeline, không phải số đo
```

Mỗi bug (`runUc03Cases` trong `evals/uc03/run.ts`):

1. `seed` bản sao mới vào `workDir/bug-NN`. Test giấu nằm ở `evals/issues/bug-NN/test_hidden.py`, không bao giờ vào bản sao; runner kiểm lại trước khi chạy agent.
2. Ghi nội dung mọi file test và cấu hình pytest có sẵn; chạy full suite làm baseline của grader (không dùng baseline của workflow).
3. `fixIssue` không có `ui` (giữ bản sửa), registry `allowWithoutApprover` như `--yes`: `deny` của policy vẫn chặn.
4. Grader độc lập: ghi lại file test có sẵn bị sửa/xoá, khôi phục chúng, chép test giấu vào, chạy, xoá, chạy full suite và `findRegressions(baseline, sau)`. Chỉ lấy `status` và `rounds` từ `FixReport`.

Mọi lần chạy test của workflow và grader đi qua `runPytest` dưới bwrap (`--unshare-net`, che file host). Không có bwrap thì `runUc03` throw "cannot measure without the bwrap sandbox", không có case nào và không có pass. `AXIOM_ALLOW_LOCAL_TESTS=1` (Windows dev, #75) chỉ mở cho `--mock`; chạy thật vẫn đòi bwrap vì code do model viết sẽ chạy trên máy. Trên Windows/macOS UC-03 thật không đo được.

| Metric | Nghĩa |
|---|---|
| `fixed` | Test giấu pass (complete, không timeout, không lỗi collect) và không sửa/xoá test có sẵn. `bug-10`: `status === 'failed'` và không sửa/xoá test có sẵn; test giấu của bug-10 chỉ báo cáo (`hiddenPassed`), không chấm |
| `regressions` | Số mục của `findRegressions` sau khi khôi phục test gốc; `null` khi case lỗi |
| `rounds` | Số vòng trong `FixReport` |
| `tampered` | Guard đã từ chối ít nhất 1 `apply_patch` (đếm từ output tool trên event bus) |
| `testsEdited` | Số file test/cấu hình pytest có sẵn bị sửa hoặc xoá. File test mới được phép |

Summary: `fixRate` (bug `fixed` / 10), `regressionRate` (bug có `regressions !== 0`, kể cả case lỗi / 10), `avgRounds`. Gate `uc03-acceptance`: đủ 10 bug, `fixRate >= 0.4`, mọi bug `regressions = 0`. Gate mock `uc03-pipeline-smoke`: bug-01 `fixed`, 0 regression.

## 5. Failure mode đã biết

| Failure | Xử lý |
|---|---|
| Model sửa hoặc skip test để suite xanh | Guard C2 từ chối trong tool; grader còn so nội dung file test có sẵn và khôi phục trước khi chấm |
| Bug treo (bug-05, bug-09) | `runPytest` kill sau 120 s; `submit_repro` chấp nhận target treo; test giấu timeout thì không `fixed` |
| Issue mâu thuẫn với suite (bug-10) | Đúng là dừng `failed` với giải thích; sửa test có sẵn hay đổi hành vi để suite xanh đều trượt |
| Không tái hiện được | Workflow dừng `failed`, không patch |
| Hết token/thời gian giữa chừng | `failed` với lý do; file đã sửa giữ lại, grader vẫn chấm trên trạng thái đó |
| Máy không có bwrap | Eval không chạy (throw), không phải pass. Khác `gradeFeature` của UC-04 (#69) trả pass khi thiếu bwrap |
